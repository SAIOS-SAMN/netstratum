# THE CHRONICLE FEED — the Terminal Wall (JOURNAL-1 directive)

**Status:** LANDING SPEC — dispatched to a coder node 2026-07-27. The GUI
course-correction problem is solved by going diegetic: no WebGL, no render
ambiguity. Civilizations SPEAK — one journal entry per year — and the feed
is the observation surface.

**The premise (operator):** "what is *your* civilization doing and how can
*I* find entertainment in that? Are you building spaceships or harvesting
honeydew — no one really knows." Growth, stagnation, needs, and leisure
become readable — and therefore economically actionable intelligence.

## 1. The laws (binding on the implementation)

1. **The journal is a RENDERING, never state.** No new chronicle events, no
   receipts, no simulation reads. It generates mirror-side from the
   chronicle + committed state (the reflection law). Deleting every journal
   changes nothing; regenerating reproduces it byte-identically.
2. **Deterministic narrative.** Same chronicle ⇒ same journal. Flavor
   selection (leisure lines, phrasing variants) seeds from receipt digests
   already in the chronicle — no wall clock, no ambient randomness.
3. **Exact rationals as `p/q` strings** (C2R): growth, joules, sink,
   ratios. Never floats, never truncated integers.
4. **Terminology law holds:** Furnace (never Crucible), no set-letter
   glyphs, world-book names from `06` (Emberkin, Coherent, Glasskeepers,
   Marrow; archetype labels like "Radiotroph" allowed as the physiology
   register).
5. **A year = 60 ticks** (placeholder) — one field of the TUniversal
   base-60 odometer; the entry header shows the odometer cycle.

## 2. State→text mapping (all from EXISTING state)

| source | narrative |
|---|---|
| banked joules vs heating need | surplus → building/expanding; deficit → RED alert: fuel sought before freeze-lock |
| famine list / freeze-lock | RED alert per resource, dormant zones named |
| overheat / `entropy_vented` delta | thermal stress, radiator exhaustion vs pristine syntropic operations |
| banked sink + vault band | offering absorption capacity to Furnace traders |
| zone mix + growth (receipts this year) | what they BUILT; growth rate as exact `p/q` per year |
| registry axes (disposition/metabolism/perception) + StarClass/band | leisure & culture flavor (digest-seeded variants) |
| chartered daughters / entities registered | expansion, population notes, "seeking space" |

Trade requests derive: joule deficit → seeking fuel; high sink → selling
`S_cool`; famine → seeking the famined resource. Alert levels: Normal
(cyan) · Warning (red) · Milestone (blue).

## 3. Surfaces

- **`var/worlds/<w>/journal.jsonl`** — one JSON line per year per world:
  tick, cycle odometer, world, civilization, archetype, headline, body,
  alert, economic summary (exact strings), optional trade_request.
- **`var/worlds/wall.html`** — the Terminal Wall: static, self-contained
  (inline CSS/JS, no external fetches), regenerated by the mirror each
  sweep. Cyber-noir: background `#0a0a10`, neon blue `#00f3ff`
  headers/metadata, neon cyan `#00ffbf` body, neon red `#ff0055` alerts.
  Single-column newest-first card feed; client-side filter bar (sector /
  faction / alert type). Display animation may be free; CONTENT is static.
- Conductor writes journals + wall on year boundaries; CLI gains `journal`
  (print this world's feed, styled).

## 4. Witnesses (land with the code)

Deterministic regeneration (same chronicle ⇒ byte-identical journal);
famine year ⇒ red-alert entry naming the resource; growth math exact;
surplus vs deficit narratives flip on the exact boundary; wall.html
contains the entries and only inline assets; a journal-free replay is
unaffected (rendering-only proof).
