The population net-delta at the collect touch, then `settle_population`.
Model (all from rulings). Put the computation next to `ration_touch_delta`

right where `ration_touch_delta` is already called (before `touch()`).

```
p = population_of(orb);   if p==0 { None }           # needs a seed (clones)
Ration::Resource(res) = ration_of(orb) else None     # element-eaters → #29
dt = stamp − last_touch;   if dt==0 { None }
per_capita = metabolic_harvest_of(metab, elem).1 / 2  # R6 half-harvest
demand     = ratio(p) * per_capita * ratio(dt)        # food the people need
mortality  = p * dt / L                               # R7b combined, L=lifespan_of()  (u64 math)
bank = held.banked_amount(res)                        # standing ration
if bank >= demand:                        # FED
    births = (grained_logistic(ratio(p), population_capacity(orb), intrinsic_rate(metab,elem), dt) - ratio(p)).floor()  # →i64 via .floor() then numer
    Δpop = births - mortality
    consumed = demand
else:                                     # STARVED
    fed = (bank / per_capita / ratio(dt)).floor()     # people the bank can feed
    Δpop = -(mortality + (p as i64 - fed))
    consumed = bank
# fold `-consumed` into the ration settleable at collect (a debit, mirrors regrowth credit),
# and self.settle_population(orb, Δpop) at the same touch. Ration.floor() exists (stock.rs:98);
# BigInt→i64: floored.numer().try_into().unwrap_or(saturate).
```

## Key patterns / gotchas (earned this arc)

  folds into an existing touch's receipt (regrowth→YieldCollected) so
  replay banks from the receipt — SEAL-B-safe, no new deed. Only
